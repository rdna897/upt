# Security

Docker Update Manager controls Docker and reads Compose configuration, so reports
may contain host paths, image names, or other operational metadata. Do not attach
live configuration, `.env` files, Docker credentials, the state database, or
recovery backups to an issue.

Report suspected vulnerabilities privately to the repository owner through
GitHub's private vulnerability reporting feature. Do not open a public issue for
a vulnerability or include credentials in a report.

Before sharing diagnostic output, review it for hostnames, addresses, paths, and
image names that identify private infrastructure.
